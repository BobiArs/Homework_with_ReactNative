# Практичне завдання: Todo App 2.0 — Таб-навігація, Статистика завдань та Динамічна тема

У цьому практичному завданні ви розширите свій додаток списку завдань (**`rn-todo-list`**), створений на попередньому занятті, додавши до нього повноцінну таб-навігацію (**Expo Router Tabs**), аналітику продуктивності (**Статистика**), локальне збереження в **`AsyncStorage`** та систему динамічної зміни теми (**Світла / Темна**).

---

## 🎯 Мета завдання

1. Перевести структуру додатку `rn-todo-list` на файловий роутинг із нижньою панеллю вкладок (**Tab Navigation**).
2. Створити **3 функціональні вкладки**:
   - 📝 **Завдання (`app/(tabs)/index.tsx`)** — основний список справ, форма додавання, чекбокси виконання та видалення.
   - 📊 **Статистика (`app/(tabs)/stats.tsx`)** — аналітичні картки продуктивності (всього завдань, активні, виконані, відсоток прогресу).
   - ⚙️ **Налаштування (`app/(tabs)/settings.tsx`)** — перемикання теми оформлення (Світла / Темна) зі збереженням вибору в `AsyncStorage`, а також кнопки масових дій (наприклад, "Видалити всі завершені").
3. Реалізувати глобальний контекст теми (`ThemeContext` + `useTheme`), який автоматично адаптує кольори всіх компонентів, таб-бару та системного статус-бару.
4. Оформити інтерфейс за допомогою векторних іконок з бібліотеки **`@expo/vector-icons`** (`Ionicons` або `MaterialIcons`).

## 📋 Покроковий план виконання

### Крок 1: Встановлення необхідних пакетів

Переконайтеся, що у вашому проєкті встановлено бібліотеку для локального збереження:

```bash
npx expo install @react-native-async-storage/async-storage
```

---

### Крок 2: Створення системи тем (`context/ThemeContext.tsx`)

1. Опишіть інтерфейс палітри кольорів `ThemeColors`:
   - `bg` — головне тло екрана.
   - `surface` — тло карток, форми та елементів списку.
   - `text` — основний колір тексту.
   - `textMuted` — колір підписів та неактивних елементів.
   - `border` — колір меж і розділювачів.
   - `primary` — акцентний колір (кнопки, активна вкладка).
   - `success` — колір для виконаних завдань.
   - `danger` — колір для кнопок видалення.
   - `statusBarStyle` — `"light"` або `"dark"`.
2. Створіть два колірні набори: `lightColors` та `darkColors`.
3. Реалізуйте `ThemeProvider`, який:
   - Зчитує збережений стан теми при старті додатку за ключем `@todo_theme_mode`.
   - Надає функцію `toggleTheme()`, яка перемикає тему та зберігає новий стан в `AsyncStorage`.
4. Створіть кастомний хук `useTheme()` для зручного доступу до кольорів у будь-якому компоненті.

---

### Крок 3: Налаштування кореневого макета `app/_layout.tsx`

1. Обгорніть навігатор `Stack` у `SafeAreaProvider` та `ThemeProvider`.
2. Налаштуйте динамічний рядок стану:
   ```tsx
   <StatusBar style={isDarkMode ? "light" : "dark"} />
   ```
3. Вимкніть стандартний заголовок стеку (`headerShown: false`) для групи `(tabs)`.

---

### Крок 4: Налаштування панелі вкладок `app/(tabs)/_layout.tsx`

1. Налаштуйте компонент `<Tabs>` із 3 екранами:
   - `name="index"` (Завдання): іконка `checkbox-outline` або `list-outline` (з `Ionicons`).
   - `name="stats"` (Статистика): іконка `stats-chart-outline` або `analytics-outline`.
   - `name="settings"` (Налаштування): іконка `settings-outline`.
2. Підключіть хук `useTheme()` та стилізуйте таб-бар:
   - `tabBarActiveTintColor`: `colors.primary`.
   - `tabBarInactiveTintColor`: `colors.textMuted`.
   - `tabBarStyle`: фон `colors.surface`, межа `colors.border`, адаптивна висота та відступи під iOS/Android.

---

### Крок 5: Вкладка "Завдання" (`app/(tabs)/index.tsx`)

1. Перенесіть існуючий функціонал списку завдань у файл `app/(tabs)/index.tsx`.
2. Адаптуйте стилі компонентів під тему (`colors.bg`, `colors.surface`, `colors.text`):
   - Поле введення `TextInput` у `TodoForm`.
   - Елементи списку `TodoItem` (текст, колір чекбокса, колір закресленого виконаного завдання).
3. Використайте іконки з `@expo/vector-icons` для:
   - Чекбокса виконання завдання (наприклад, `checkmark-circle` / `ellipse-outline`).
   - Кнопки видалення завдання (наприклад, `trash-outline`).

---

### Крок 6: Вкладка "Статистика" (`app/(tabs)/stats.tsx`)

Створіть екран аналітики продуктивності, який динамічно розраховує показники на основі списку завдань:

1. **Картки показників:**
   - 📌 **Всього завдань** (Total tasks).
   - ⏳ **В процесі / Активні** (Pending/Active tasks, `completed === false`).
   - ✅ **Виконані завдання** (Completed tasks, `completed === true`).
   - 📈 **Відсоток виконання** (`Math.round((completed / total) * 100)%` або `0%`, якщо завдань немає).
2. **Оформлення:**
   - Картки мають бути акуратно розміщені сіткою (grid / flex).
   - Кожна картка має тематичну іконку з `@expo/vector-icons` та акцентний колір.
   - Підтримка світлої/темної теми (`colors.surface`, `colors.text`).

---

### Крок 7: Вкладка "Налаштування" (`app/(tabs)/settings.tsx`)

Створіть екран налаштувань додатку:

1. **Блок перемикання теми:**
   - Назва поточної теми ("Світла тема" / "Темна тема") з відповідною іконкою (`sunny` / `moon`).
   - Компонент `Switch` для миттєвого перемикання теми.
2. **Блок дій із завданнями (Додатково):**
   - Кнопка **"Очистити виконані завдання"** (з діалоговим вікном підтвердження `Alert.alert`).
   - Кнопка **"Видалити всі завдання"**.
3. **Блок "Про додаток":**
   - Назва додатку та версія (наприклад, `v2.0.0`).

## 💎 Поради щодо організації спільного стану завдань

Щоб список завдань був доступний одночасно на екрані **Завдань** (для додавання/видалення) та на екрані **Статистики** (для підрахунку показників), рекомендується винести масив `todos` та функції роботи з ним у спільний **`TodoContext`** або зберігати їх в `AsyncStorage`:

```tsx
// Приклад структури TodoContext
interface TodoContextType {
  todos: Todo[];
  addTodo: (text: string) => Promise<void>;
  toggleTodo: (id: string | number) => Promise<void>;
  deleteTodo: (id: string | number) => Promise<void>;
  clearCompleted: () => Promise<void>;
  clearAll: () => Promise<void>;
}
```
