# Домашнє завдання (Модуль 1)

## Завдання

1. **Розширте сторінку "Моє місто" (`city.tsx`):**
   - Додайте **список визначних місць** вашого міста (мінімум 3 місця).
   - Для кожного місця вкажіть назву та короткий опис (1-2 речення).
   - Використайте компонент `FlatList` або `ScrollView` для відображення списку.

2. **Створіть сторінку "Про мене" (`about.tsx`):**
   - Створіть новий файл `about.tsx` у папці `app`.
   - Додайте **ваше ім'я** як заголовок.
   - Додайте **ваше фото або аватар** (можна використати placeholder).
   - Напишіть **короткий опис про себе**: хобі, улюблені заняття, чому вирішили вивчати React Native (3-5 речень).
   - Додайте **список ваших навичок або інтересів** (мінімум 4 пункти).

3. **Стилізуйте обидві сторінки:**
   - Використайте **єдину кольорову схему** для обох сторінок (оберіть 2-3 основні кольори).
   - Створіть **картки** для кожного елемента списку з тінню або рамкою.
   - Додайте **іконки** до списків (можна використати emoji або бібліотеку `@expo/vector-icons`).
   - Застосуйте **різні розміри шрифтів** для заголовків, підзаголовків та основного тексту.
   - Всі стилі повинні бути в `StyleSheet.create()`.

4. **Створіть навігацію між сторінками:**
   - На головній сторінці (`index.tsx`) додайте дві кнопки:
     - "Моє місто" → перехід на `city.tsx`
     - "Про мене" → перехід на `about.tsx`
   - Використайте `Link` з `expo-router` для навігації.

## Підказки

### Приклад використання `FlatList`:

```tsx
import { FlatList, Text, View, StyleSheet } from "react-native";

const places = [
  {
    id: "1",
    name: "Парк Шевченка",
    description: "Великий парк у центрі міста",
  },
  {
    id: "2",
    name: "Оперний театр",
    description: "Історична будівля 19 століття",
  },
  {
    id: "3",
    name: "Набережна",
    description: "Мальовниче місце для прогулянок",
  },
];

<FlatList
  data={places}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => (
    <View style={styles.card}>
      <Text style={styles.placeName}>{item.name}</Text>
      <Text style={styles.placeDescription}>{item.description}</Text>
    </View>
  )}
/>;

const styles = StyleSheet.create({
  card: {
    backgroundColor: "#fff",
    padding: 16,
    marginVertical: 8,
    borderRadius: 8,
    shadowColor: "#000",
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.1,
    shadowRadius: 4,
    elevation: 3,
  },
  placeName: {
    fontSize: 18,
    fontWeight: "bold",
    marginBottom: 4,
  },
  placeDescription: {
    fontSize: 14,
    color: "#666",
  },
});
```

### Приклад навігації з Expo Router:

```tsx
import { Link } from "expo-router";
import { Text, StyleSheet } from "react-native";

<Link href="/city" style={styles.link}>
  <Text style={styles.linkText}>Моє місто</Text>
</Link>;
```

### Приклад використання іконок:

```tsx
import { Ionicons } from "@expo/vector-icons";

<Ionicons name="home" size={24} color="black" />;
```

## Критерії оцінювання

- **Функціональність** (40%): Всі сторінки створені, навігація працює, інтерактивність реалізована.
- **Стилізація** (30%): Єдина кольорова схема, акуратний дизайн, правильне використання `StyleSheet`.
- **Код** (20%): Чистий код, правильна структура компонентів, відсутність помилок.
- **Звіт** (10%): Повні відповіді на всі питання, демонстрація розуміння матеріалу.
