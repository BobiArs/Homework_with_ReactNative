У цьому завданні ми реалізуємо одну з найпопулярніших та технічно насичених функцій топових месенджерів (**Telegram, WhatsApp, Slack, Instagram Direct**) — **систему реакцій на повідомлення з плаваючим пікером емодзі**.

Ми поєднаємо:

1. **Зв'язок баз даних у Convex** — окрема таблиця реакцій, мутація перемикання та агрегація кількості реакцій у режимі реального часу.
2. **Композицію жестів Gesture Handler v2** — подвійний тап (`Double-Tap`) для миттєвого лайка `❤️` та довге затискання (`Long-Press`) для виклику меню.
3. **Визначення нативних координат на екрані (`measureInWindow`)** — плаваюче меню з'являється не десь по центру, а точно над натиснутим повідомленням, враховуючи, чи це повідомлення відправника чи співрозмовника.
4. **Фізику анімацій Reanimated / Animated** — пружинне розкриття меню емодзі з точки прив'язки (`transformOrigin`) та анімована поява бейджів реакцій.
5. **Тактильний відгук (`expo-haptics`)** — жива тактильна вібрація при взаємодії.

## 🎯 Мета завдання

1. **Оновлення схеми та бекенду Convex (`convex/schema.ts`, `convex/messages.ts`):**
   - Створити нову таблицю `messageReactions` з полями `messageId`, `userId`, `emoji` та індексами `by_message` і `by_user_and_message`.
   - Реалізувати мутацію `toggleReaction`:
     - Якщо користувач тисне на той самий емодзі повторно — реакція видаляється (toggle off).
     - Якщо обирає інший емодзі — попередня реакція замінюється на нову.
     - Якщо реакції ще не було — створюється новий запис.
   - Оновити пагінований запит `getPaginatedMessages` для агрегації реакцій: групування за типом емодзі, підрахунок кількості (`count`) та визначення, чи поставив поточний користувач цю реакцію (`hasReacted`).

2. **Оновлення жестів у `components/SwipeableMessageItem.tsx`:**
   - Додати посилання `containerRef` (`useRef<View>(null)`) до кореневого елемента повідомлення.
   - **Double-Tap:** швидкий подвійний тап (`Gesture.Tap().numberOfTaps(2)`) ставить або знімає швидкий лайк `❤️` з легким вібро-відгуком `Haptics.impactAsync(Light)`.
   - **Long-Press:** затискання повідомлення на 350 мс викликає `containerRef.current?.measureInWindow(...)`, обчислює абсолютні екранні координати (`x`, `y`, `isOwn`) та передає їх на екран чату.
   - Об'єднати жести за допомогою `Gesture.Exclusive(doubleTapGesture, longPressGesture)` та скомпонувати із жестом свайпу відповіді `Gesture.Simultaneous(...)`.

3. **Плаваюче модальне вікно вибору емодзі (`components/ReactionPickerModal.tsx`):**
   - Напівпрозора підкладка `Pressable` для закриття меню при дотику поза баблом.
   - Абсолютно позиціонований бабл із набором популярних емодзі (`❤️`, `👍`, `😂`, `😮`, `😢`, `🔥`, `🎉`, `👏`).
   - Автоматичний розрахунок координат: пікер розташовується **над** повідомленням (якщо зверху мало місця — знизу), вирівнюючись по стороні бульбашки (`isOwn ? правий_край : лівий_край`).
   - Пружинне розкриття меню за допомогою `transformOrigin` (`position.isOwn ? "100%" : "0%" 100%`) та `Animated.spring`.
   - Відправка обраного емодзі з вібрацією та автоматичне закриття пікера.

4. **Анімовані бейджі реакцій (`components/MessageReactions.tsx`):**
   - Відображення списку реакцій безпосередньо у бульбашці повідомлення (під основним текстом).
   - Підкомпонент `ReactionPill`: плавна пружинна поява бейджа при першому рендері (scale + opacity).
   - Візуальне підсвічування кольором `primary` для емодзі, на які відреагував поточний авторизований користувач.
   - Інтерактивність: можливість натиснути на вже існуючу пілюлю реакції, щоб швидко приєднатися до неї (+1) або зняти свій голос.

5. **Інтеграція в екран чату (`app/chat/[id].tsx`):**
   - Стан `pickerState: { messageId: Id<"messages">; position: ReactionPickerPosition } | null`.
   - Підключення мутації `api.messages.toggleReaction`.
   - Виправлення кореневого контексту: переконатися, що `GestureHandlerRootView` огортає весь додаток в `app/_layout.tsx`, а не дублюється всередині кожного елемента списку.

## 🛠 Стек технологій

- **Фреймворк:** React Native / Expo SDK 52+ (Expo Router v4)
- **Бекенд & Realtime DB:** [Convex](https://convex.dev) (`messageReactions`, `toggleReaction`, агрегація)
- **Жести:** `react-native-gesture-handler` v2 (`Gesture.Tap(2)`, `Gesture.LongPress()`, `Gesture.Exclusive`, `Gesture.Simultaneous`)
- **Нативні координати:** `measureInWindow`
- **Анімації:** `react-native-reanimated` 3 та `react-native Animated` (Spring Physics, `transformOrigin`)
- **Тактильний відгук:** `expo-haptics`
- **Стилізація:** NativeWind (Tailwind CSS)

## 📋 Чекліст виконання для студента

### 1. Бекенд Convex (`convex/schema.ts` та `convex/messages.ts`):

- [ ] Створено таблицю `messageReactions` з індексами `by_message` та `by_user_and_message`.
- [ ] Мутація `toggleReaction` коректно перевіряє авторизацію через `getAuthUserId(ctx)`.
- [ ] Повторний клік на той самий емодзі видаляє реакцію з бази даних.
- [ ] Вибір нового емодзі оновлює існуючу реакцію користувача на цьому повідомленні.
- [ ] Запит `getPaginatedMessages` агрегує реакції та повертає масив `reactions: [{ emoji, count, hasReacted }]`.

### 2. Жести та визначення координат (`components/SwipeableMessageItem.tsx`):

- [ ] Швидкий подвійний тап по будь-якому повідомленню ставить або знімає сердечко `❤️`.
- [ ] При подвійному тапі спрацьовує легка вібрація `Haptics`.
- [ ] Довге затискання повідомлення (350 мс) визначає координати бульбашки через `measureInWindow` та передає їх у пікер.
- [ ] Подвійний тап і довге натискання не конфліктують між собою (`Gesture.Exclusive`).
- [ ] Горизонтальний свайп для відповіді (`Swipe-to-Reply`) та вертикальний скрол списку працюють без блокувань (`Gesture.Simultaneous`).

### 3. Плаваючий пікер реакцій (`components/ReactionPickerModal.tsx`):

- [ ] Меню реакцій з'являється безпосередньо над (або під) обраним повідомленням, а не по центру екрана.
- [ ] Для власних повідомлень пікер притискається до правого краю, для чужих — до лівого.
- [ ] Меню ніколи не виходить за межі екрана смартфону (обмеження через `Math.max` та `Math.min`).
- [ ] Меню з'являється з пружинною анімацією розширення (`transformOrigin`).
- [ ] Клік на будь-який емодзі викликає `toggleReaction`, спрацьовує вібро-відгук і модальне вікно закривається.
- [ ] Клік на затемнену підкладку закриває пікер без вибору реакції.

### 4. Відображення реакцій (`components/MessageReactions.tsx`):

- [ ] Реакції відображаються пілюлями з емодзі та цифрою-лічильником.
- [ ] Кожна пілюля з'являється з м'якою пружинною анімацією (scale + fade).
- [ ] Власна реакція підсвічується акцентним кольором (напівпрозорий `primary` фон та рамка).
- [ ] Натискання на пілюлю дозволяє іншому користувачу швидко підтримати реакцію (+1) або зняти свою.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Анімований ефект вилітаючого сердечка (Floating Heart Burst):**
   - При подвійному тапі на повідомлення показуйте велике напівпрозоре сердечко по центру бульбашки, яке пружинно збільшується до 1.4x, плавно піднімається вгору і розчиняється (`FadeOutUp` або Reanimated sequence).
2. **Список користувачів, що відреагували («Хто поставив реакцію»):**
   - При довгому натисканні на саму пілюлю реакції відкривайте компактний BottomSheet / модальне вікно зі списком аватарок та імен користувачів, які обрали цей емодзі.
