# Homework_with_ReactNative та процедура скидання проекта на GitHub

1. git init
2. git remote add origin https://github.com/BobiArs/Homework_with_ReactNative.git // Підключення до репозиторія
3. git checkout -b home-workx // Стоверення і переход на гілку де виконується Task
4. git add .
5. git commit -m "Push home-work x"
6. git push -u origin home-workx // Пушемо гілку на GitHub
