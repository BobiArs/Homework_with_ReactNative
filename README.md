## 🎯 Мета завдання

1. **Інтерактивний повноекранний переглядач фото (`components/ImageViewerModal.tsx`):**
   - Створити модальний компонент перегляду фотографій на базі `react-native-gesture-handler` та `react-native-reanimated`.
   - **Pinch-to-Zoom:** плавне масштабування фото двома пальцями від 1x до 4x (`Gesture.Pinch()`) з пружним поверненням у межі при відпусканні.
   - **Pan Gesture:** плавне панорамування збільшеної фотографії пальцем по всьому кадру (`Gesture.Pan()`).
   - **Double-Tap to Zoom:** швидке масштабування до 2.5x і назад до 1x при швидкому подвійному дотику (`Gesture.Tap().numberOfTaps(2)`).
   - **Swipe-to-Dismiss:** якщо фото у звичайному масштабі 1x, потягування вниз плавно зменшує непрозорість бекдропу, а при відпусканні нижче порогу закриває модальне вікно.
   - Підключити переглядач до фотографій у чаті (`components/SwipeableMessageItem.tsx`) та до аватарки на екрані співрозмовника (`app/user/[id].tsx`).

2. **Анімації появи та видалення повідомлень (Reanimated Layout Animations):**
   - Налаштувати плавний пружинний вхід для нових надісланих чи отриманих повідомлень за допомогою `entering={FadeInDown.springify().damping(14)}` (або `SlideInRight` для власних реплік).
   - Додати плавне розчинення при видаленні повідомлення (`exiting={FadeOutLeft.duration(200)}`), щоб список не "стрибав".
   - Додати плавне виїжджання панелі цитування `ReplyPreviewBar` (`entering={SlideInDown}` / `exiting={SlideOutDown}`).

3. **Фізичні мікроінтеракції інтерфейсу (Micro-interactions):**
   - **Spring Send Button:** пружна реакція кнопки відправки при натисканні (стискання до 0.88 через `withSpring` при дотику та миттєве пружне відновлення).
   - **Анімована плаваюча кнопка повернення вниз (Scroll to Bottom FAB):** плавна поява через `entering={ZoomIn.springify()}` та `exiting={ZoomOut}`.
   - **Пульсуючий бейдж/індикатор (Pulse Effect):** додати легку пульсацію для індикатора активності або для бейджа нових повідомлень на базі `withRepeat` і `withSequence`.

## 🛠 Стек технологій

- **Фреймворк:** React Native / Expo SDK 52+ (Expo Router v4)
- **Анімації:** `react-native-reanimated` 3 (`useSharedValue`, `useAnimatedStyle`, `withSpring`, `withTiming`, `withRepeat`, Layout Animations: `FadeInDown`, `FadeOutLeft`, `SlideInDown`, `ZoomIn`)
- **Жести:** `react-native-gesture-handler` v2 (`Gesture.Pinch()`, `Gesture.Pan()`, `Gesture.Tap()`, `Gesture.Race()`, `Gesture.Simultaneous()`, `GestureDetector`)
- **Бекенд:** Convex Realtime Database
- **Стилізація:** NativeWind (Tailwind CSS)

## 📋 Чекліст виконання для студента

### 1. Повноекранний переглядач фото (`components/ImageViewerModal.tsx`):

- [ ] Створено компонент `ImageViewerModal.tsx` на основі нативного `Modal` та `GestureDetector`.
- [ ] При тапі на прикріплене зображення у повідомленні воно відкривається на весь чорний екран зі збереженням пропорцій (`resizeMode="contain"`).
- [ ] **Pinch-to-Zoom:** розведення двох пальців плавно збільшує картинку в реальному часі (до 4x). При зменшенні менше 1x пружинно повертається до початкового розміру.
- [ ] **Pan Gesture:** у збільшеному стані зображення плавно перетягується пальцем у будь-який бік, дозволяючи оглянути весь кадр.
- [ ] **Double-Tap:** подвійний швидкий дотик плавно збільшує зображення до 2.5x, а повторний подвійний дотик повертає до 1x.
- [ ] **Swipe-to-Dismiss:** при потягуванні фотографії вниз у масштабі 1x фон стає прозорішим, а при відпусканні нижче 120px модальне вікно плавно закривається.
- [ ] Присутня зручна кнопка закриття (хрестик `X`) у правому верхньому куті.
- [ ] Зум також працює при кліку на фотографію аватара на публічному екрані співрозмовника `app/user/[id].tsx`.

### 2. Анімації списку та макета (Layout Animations):

- [ ] Нові надіслані та отримані повідомлення плавно виринають у списку за допомогою Reanimated Layout Animations (`FadeInDown` / `FadeInUp`).
- [ ] Видалення власного повідомлення супроводжується плавним зникненням (`FadeOutLeft` або `FadeOut`), запобігаючи різким стрибкам списку.
- [ ] Панель відповіді `ReplyPreviewBar` висувається над інпутом через `SlideInDown` та ховається через `SlideOutDown`.

### 3. Фізика кнопок та мікроінтеракції:

- [ ] Кнопка відправки повідомлення приємно пружно стискається під пальцем при натисканні (`withSpring(0.88)` при `onPressIn` та повернення при `onPressOut`).
- [ ] Плаваюча кнопка повернення вниз (Scroll to Bottom FAB) з'являється і зникає з плавною пружиною (`ZoomIn` / `ZoomOut`).
- [ ] Індикатор набору тексту або бейдж нових повідомлень має делікатну пульсацію на базі `withRepeat`.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Вібро-відгук при подвійному тапі та свайпі закриття (`expo-haptics`):**
   - Додайте тактильну вібрацію при спрацьовуванні подвійного тапу для зуму:
     ```bash
     npx expo install expo-haptics
     ```
   - Викликайте `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light)` у момент перемикання зуму та закриття модалки.
2. **Анімований лічильник непрочитаних на кнопці FAB:**
   - Якщо користувач читає стару історію вгорі, і приходить нове повідомлення, показуйте на кнопці FAB червоний кружечок із кількістю нових реплік, який підстрибує за допомогою `withSequence(withTiming(1.3), withSpring(1))`.
