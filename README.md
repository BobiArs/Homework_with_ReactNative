## 💥 Проблема, яку ми вирішуємо

До цього моменту всі розробники тестували додаток за допомогою клієнта **Expo Go** (`npx expo start`):

1. **Залежність від комп'ютера:** Якщо зупинити сервер Metro Bundler на ПК, додаток у телефоні миттєво втрачає зв'язок і припиняє роботу.
2. **Неможливість віддати клієнту або друзям:** Ви не можете надіслати проєкт людині без встановленого середовища розробки Node.js та терміналу.
3. **Обмеження нативних модулів:** Усі нативні модулі (камера, аудіозапис, відеокружечки, безпечне сховище) вимагають повноцінних дозволів у `AndroidManifest.xml` та скомпільованого нативного C++ байткоду.
4. **Залежність від черг у хмарі:** Хмарні збірки (EAS Build у безкоштовному тарифі) вимагають очікування в чергах від 20 до 60 хвилин. Володіння локальною збіркою на власному комп'ютері дає розробнику повну незалежність і швидкість компіляції за 1–3 хвилини.

Ми опановуємо професійний інженерний цикл: налаштовуємо **OpenJDK 17**, **Android SDK Build-Tools**, генеруємо нативний проєкт через `npx expo prebuild`, компілюємо автономні **Debug** та **Release APK** за допомогою Gradle і тестуємо на реальному пристрої через **ADB**!

## 🎯 Мета та задачі завдання

### 1. Налаштування системного середовища та динамічна конфігурація

- **Перевірка Java Development Kit:** Встановлення та верифікація **OpenJDK 17** (`javac -version`).
- **Android SDK:** Налаштування змінних оточення `ANDROID_HOME`, `JAVA_HOME` та оновлення `PATH` для доступу до утиліти `adb`.
- **Динамічний `app.config.ts`:**
  - Підтримка середовищ збірки (`APP_ENV=development` ➔ `Modern Chat Dev` / `com.modernchat.app.dev`, `APP_ENV=production` ➔ `Modern Chat` / `com.modernchat.app`).
  - Налаштування адаптивної іконки (`./assets/images/android-icon-foreground.png`).
  - Збереження конфігурацій усіх нативних плагінів: `expo-audio`, `expo-camera`, `expo-splash-screen`, `expo-image-picker`, `expo-secure-store`.
- **Змінні середовища Convex:** Перевірка доступності `EXPO_PUBLIC_CONVEX_URL` у `.env.local` на етапі збірки.

### 2. Генерація нативного коду (Continuous Native Generation)

- Виконання команди `npx expo prebuild --platform android --clean`.
- Перевірка створення папки `android/` із системним файлом `AndroidManifest.xml` та скриптом `gradlew`.
- Налаштування файлу `android/local.properties` із точним шляхом до `sdk.dir`.
- Оптимізація пам'яті JVM у `android/gradle.properties` (`-Xmx4096m -XX:MaxMetaspaceSize=1024m`) для запобігання збоїв збірки C++ модулів React Native.

### 3. Локальна компіляція APK через Gradle

- **Збірка Debug APK:** Успішний запуск `./gradlew assembleDebug` та отримання файлу `app-debug.apk`.
- **Збірка Release APK (Рекомендовано / Бонус):** Компіляція повністю автономного оптимізованого білду `./gradlew assembleRelease` без налагоджувального оверхеду.
- Завершення компіляції зі статусом **`BUILD SUCCESSFUL`**.

### 4. Встановлення та автономне тестування на реальному пристрої або емуляторі

- Увімкнення режиму розробника та USB-налагодження на смартфоні Android.
- Встановлення згенерованого APK за допомогою утиліти `adb install -r`.
- Автономний запуск додатку **із зупиненим сервером Metro Bundler** (`npx expo start` зупинено).
- Перевірка роботи автентифікації Convex Auth, завантаження історії повідомлень, відправки фотографій, запису голосових повідомлень та зйомки відеокружечків.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Збірка автономного Release APK (`assembleRelease`):**
   - Більшість початківців обмежуються лише Debug APK. Скомпілюйте фінальний оптимізований **Release APK** (`./gradlew assembleRelease`) з продакшн-конфігурацією (`APP_ENV=production`), де JavaScript бандл попередньо скомпільований у байткод Hermes.
2. **Локальна збірка через EAS CLI (`eas build --local`):**
   - Налаштуйте файл `eas.json` з профілем `preview` (`"buildType": "apk"`) та збережіть APK однією декларативною командою:
     ```bash
     npx eas-cli build --platform android --profile preview --local
     ```
3. **Генерація власного релізного ключа Keystore:**
   - Згенеруйте персональний ключ підпису додатків за допомогою утиліти `keytool` та налаштуйте блок `signingConfigs.release` у `android/app/build.gradle`.

## 📤 Формат здачі завдання

Для зарахування домашнього завдання надайте:

1. **Скріншот терміналу** з фінальним повідомленням успішної компіляції:
   ```text
   BUILD SUCCESSFUL in 3m 45s
   xxx actionable tasks: xxx executed
   ```
2. **Скріншоти з пристрою (фізичний смартфон або емулятор):**
   - Скріншот робочого столу смартфона, де видно іконку та назву вашого встановленого додатку (`Modern Chat` або `Modern Chat Dev`).
   - Скріншот запущеного автономного додатку з успішним відображенням чатів та даних із бази Convex.
   - Скріншот роботи мультимедійного функціоналу (наприклад, вікна зйомки відеокружечка або відтворення аудіохвилі).
3. **Файл APK:**
   - Додайте готовий файл `app-release.apk` (або `app-debug.apk`) до архіву завдання або завантажте його на Google Drive / хмарне сховище та додайте посилання з відкритим доступом.
4. **Короткий текстовий опис у звіті:**
   - Операційна система вашого комп'ютера (Windows / macOS / Linux).
   - Тип білду (Debug чи Release) та час компіляції.
   - Які системні труднощі виникли під час збірки та як ви їх розв'язали.

## 🧪 Чекліст для самоперевірки

- [ ] Команда `javac -version` повертає версію `17.x.x`.
- [ ] Змінна `ANDROID_HOME` налаштована, а команда `adb --version` викликається у терміналі.
- [ ] Ліцензії Android SDK прийняті (`sdkmanager --licenses`).
- [ ] Файл `app.config.ts` успішно проходить перевірку `npx expo config --type public`.
- [ ] Папку `android/` успішно згенеровано командою `npx expo prebuild --platform android --clean`.
- [ ] У `android/local.properties` вказано точний шлях до вашого Android SDK (`sdk.dir`).
- [ ] Команда `./gradlew assembleDebug` або `./gradlew assembleRelease` завершилася зі статусом `BUILD SUCCESSFUL`.
- [ ] Файл `.apk` знайдено у папці `android/app/build/outputs/apk/...`.
- [ ] Смартфон виявляється командою `adb devices`.
- [ ] Додаток встановлено через `adb install` та запускається автономно без комп'ютера розробника.
- [ ] Працюють мережеві запити до Convex та нативні дозволи на камеру/мікрофон.

Перебілд на ПК (Windows):

- npx expo prebuild --platform android --clean

Запуск Debug або Release збірки:

- cd android
  .\gradlew.bat assembleDebug або ./gradlew assembleRelease
