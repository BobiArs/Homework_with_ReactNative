## 💥 Проблема, яку ми вирішуємо

До цього моменту мультимедійні можливості чату були базовими:

1. **Тільки звичайні фото та аудіо:** Не було підтримки популярного та живого формату спілкування — круглих відеоповідомлень (Video Notes / "кружечків"), які записуються в один дотик.
2. **Повільне прослуховування:** Довгі голосові та відеоповідомлення можна було слухати лише у звичайному темпі `1x`, що забирає багато часу у користувачів.
3. **Статичний аудіоплеєр:** Замість сучасної звукової хвилі голосові повідомлення мали звичайну плоску смужку прогресу, без розуміння амплітуди мови та без можливості зручно перемотати аудіо тапом на потрібну секунду.
4. **Сліпий запис:** Користувач під час запису аудіо не бачив візуального відгуку свого голосу.

Ми впроваджуємо повноцінний сучасний медіа-стек: **`expo-camera`**, **`expo-video`**, **`expo-audio`**, нормалізацію амплітуд звуку, зміну темпу `playbackRate` та векторну графіку!

## 🎯 Мета та задачі завдання

### 1. Схема бази даних та бекенд Convex (`convex/schema.ts`, `convex/messages.ts`)

- **Поля для круглих відео:**
  - `videoUrl: v.optional(v.string())`
  - `videoStorageId: v.optional(v.id("_storage"))`
  - `videoDuration: v.optional(v.number())`
  - `isVideoNote: v.optional(v.boolean())`
- **Поле для звукової хвилі:**
  - `waveform: v.optional(v.array(v.number()))` — масив 30–32 нормалізованих чисел `[0.1 .. 1.0]`.
- **Оновлення мутації `sendMessage`:**
  - Збереження нових полів у таблицю `messages`.
  - Формування правильного прев'ю останнього повідомлення для списку бесід (`📹 Відеоповідомлення`, `🎤 Голосове повідомлення (12с)`).

### 2. Круглі відеоповідомлення (Telegram-style Video Notes)

- **Запис кружечків (`VideoNoteRecorderModal.tsx`):**
  - Використання `CameraView` з пакета **`expo-camera`** у режимі `mode="video"` та фронтальною камерою (`facing="front"`).
  - Кругла маска огляду камери (`borderRadius: 125`) з круговим SVG-таймером запису до 60 секунд.
  - Завантаження знятого `.mp4` файлу у Convex Storage через `expo/fetch` та відправка у чат.
- **Перегляд кружечків (`VideoNotePlayer.tsx`):**
  - Використання швидкого нативного відеоплеєра **`expo-video`** (`useVideoPlayer`, `VideoView`).
  - Ідеально кругла форма (`borderRadius: 100`, розмір 200x200).
  - Тап по кружечку перемикає звук/паузу (як у Telegram).
  - Круговий SVG або прогрес-бар навколо кружечка, що показує хід перегляду.

### 3. Керування швидкістю відтворення (1x / 1.5x / 2x)

- **Циклічне перемикання:**
  - Кнопка швидкості з режимами **`1x` ➔ `1.5x` ➔ `2x` ➔ `1x`**.
  - Застосовується як до голосових повідомлень (`VoiceMessagePlayer`), так і до круглих відеонотаток (`VideoNotePlayer`).
- **Нативна зміна швидкості:**
  - Встановлення `player.playbackRate` у `expo-audio` та `expo-video`.
  - Автоматична корекція тональності (Pitch Correction): голос прискорюється без ефекту «мультяшного» пищання.
- **Візуальний та тактильний відгук:**
  - Підсвічування кнопки акцентним кольором (`COLORS.primary`), коли швидкість > `1x`.
  - Тактильний відгук через **`expo-haptics`** (`ImpactFeedbackStyle.Light`).

### 4. Візуалізація звукової хвилі (Audio Waveform)

- **Компонент `AudioWaveform.tsx`:**
  - Відображення 32 вертикальних стовпчиків із закругленими краями (`borderRadius: 2`).
  - Візуальний поділ: відтворена частина стовпчиків зафарбовується брендовим кольором, невідтворена — залишається напівпрозорою.
  - Інтерактивне перемотування (**Seek / Scrubbing**): дотик або свайп по стовпчиках миттєво перемотує аудіо на відповідну позицію за допомогою `player.seekTo(targetSeconds)`.
  - Надійна генерація резервної хвилі (**Fallback Waveform**) для аудіозаписів, які не мають збереженого масиву амплітуд.
- **Жива анімація запису в `ChatInput.tsx`:**
  - Під час запису голосового повідомлення поруч із таймером відображаються динамічні коливання стовпчиків хвилі.

├── app/
│   └── messages/

├── components/
│   ├── AudioWaveform.tsx               # НОВИЙ: компонент інтерактивної звукової хвилі

│   ├── ChatInput.tsx                   # Оновлено: перемикач аудіо/відео, жива хвиля при записі
│   └── MessageBubble.tsx               # Оновлено: рендеринг кружечків та передача waveform у плеєр

    ├── schema.ts                       # Поля videoUrl, videoDuration, isVideoNote, waveform
    └── messages.ts                     # Збереження нових медіа-полів у sendMessage

## 🧪 Чекліст для самоперевірки

- [ ] У таблиці `messages` присутні всі нові поля: `videoUrl`, `videoDuration`, `isVideoNote`, `waveform`.
- [ ] У `ChatInput` можна перемикатися між записом голосового повідомлення та зйомкою відеокружечка.
- [ ] Під час зйомки кружечка камера має круглу маску, ведеться круговий відлік таймера (до 60 с).
- [ ] Відео успішно завантажується у Convex Storage та відображається у чаті круглим баблом.
- [ ] Тап по відеокружечку вмикає/вимикає звук або ставить на паузу.
- [ ] У плеєрі голосових повідомлень замість звичайного повзунка відображаються стовпчики амплітуд звуку.
- [ ] Тап по будь-якому стовпчику хвилі миттєво переносить відтворення на цю секунду (Seek).
- [ ] Кнопка швидкості (1x / 1.5x / 2x) коректно прискорює аудіо та відео з тактильним відгуком.
- [ ] При записі голосового повідомлення стовпчики хвилі динамічно коливаються в такт відліку таймера.
- [ ] Команда `npx tsc --noEmit` проходить без жодних помилок компіляції.
