# Todo React App (з json-server)

Простий та сучасний додаток списку завдань (Todo App) на React + TypeScript (Vite), інтегрований з REST API на базі `json-server`.

---

## 🚀 Як запустити проєкт

### 1. Запуск сервера (`json-server`)
У першому терміналі перейдіть у папку `server` і запустіть сервер:
```bash
cd ../server
npm start
```
Сервер буде доступний за адресою: [http://localhost:3000/todos](http://localhost:3000/todos). Дані зберігаються у файлі `server/db.json`.

---

### 2. Запуск клієнтської частини (`todo-react`)
У другому терміналі запустіть клієнтський додаток:
```bash
cd todo-react
npm run dev
```
Відкрийте браузер за адресою [http://localhost:5173](http://localhost:5173).

---

## ✨ Функціонал додатку
- **Завантаження завдань**: Отримання списку завдань через `GET /todos`.
- **Додавання**: Створення нового завдання через `POST /todos`.
- **Зміна статусу**: Позначення як виконане / невиконане через `PATCH /todos/:id`.
- **Редагування**: Зміна тексту завдання через кнопку ✏️ або подвійний клік на текст (`PATCH /todos/:id`).
- **Видалення**: Видалення завдання через кнопку 🗑️ (`DELETE /todos/:id`).
- **Фільтрація**: Перемикання між вкладками **Всі**, **Активні**, **Виконані**.
- **Очищення**: Видалення всіх виконаних завдань в один клік.
- **Обробка помилок**: Інформаційне повідомлення з кнопкою повтору, якщо сервер не запущено.

---

## 🛠️ Стек технологій
- **Frontend**: React 19, TypeScript, Vite, CSS3.
- **Backend / Mock API**: `json-server` (порт 3000).
